Simulation Guide & Controls

This interactive studio simulates the 3 fundamental uninformed search algorithms in Artificial Intelligence:

  • Breadth-First Search (BFS): Uses a First-In-First-Out (FIFO) queue to explore the graph level by level. Guarantees shortest path in hop count.
  • Depth-First Search (DFS): Uses a Last-In-First-Out (LIFO) stack to plunge down branches before backtracking. Low memory footprint, but not cost-optimal.
  • Uniform Cost Search (UCS): Expands the frontier node with the lowest cumulative path cost g(n) via a Min-Priority Queue. Guarantees the lowest total path cost when edge weights vary.

Assignment 1: Uninformed Search Simulation & Solutions

Part A: Agents and Problem Setup (5 marks)

A1. Reflex Agent vs. Planning Agent (2 marks)

• Old App = Reflex Agent: It acts solely on immediate condition-action rules at each junction ("turn toward nearest exit; if blocked, turn around"). It does not compute future states, consider overall journey consequences, or formulate plans ahead of time.

• New App = Planning Agent: It computes a complete sequence of actions (route from Shop $S$ to Customer $G$) before the rider leaves. It reasons about state transitions, road travel times (costs), and the goal condition to synthesize an optimal plan.

A2. Search Problem Formulation (3 marks)

  • State Space ($S$): Set of 8 road junctions in Kuching: {S, A, B, C, D, E, F, G}.
  • Start State ($s_0$): The shop junction, S.
  • Successor Function & Step Costs: From junction $u$, navigate along any outgoing one-way road to junction $v$ with travel time (minutes) as step cost $c(u, a, v)$:
    S → A : 3 mins S → B : 1 min S → C : 6 mins B → A : 1 min B → E : 5 mins A → D : 2 mins A → G : 9 mins C → G : 2 mins D → F : 1 min D → G : 3 mins E → G : 4 mins F → C : 1 min
  • Goal Test: Checks if current junction is the customer location: IsGoal(state) ≡ (state == G).

Part C: Compare and Reflect (3 marks)

C1. Fastest Route & Why BFS Missed It (2 marks)

• Fastest Search: Uniform Cost Search (UCS) found the fastest route: S → B → A → D → G taking 7 minutes.

• Why BFS Did Not Find It: Breadth-First Search is unweighted and only minimizes the number of hops (transitions). BFS found path S → A → G simply because it is only 2 hops away from the start node, even though its edge weights are long (3 + 9 = 12 minutes). BFS operates blindly without regard to edge costs and therefore cannot guarantee cost optimality when step times vary.

C2. When DFS Is a Sensible Choice (1 mark)

DFS is a sensible choice when memory/space is severely constrained. BFS and UCS store the entire exponential frontier in memory ($O(b^d)$ or $O(b^{C^*/\epsilon})$), which easily leads to memory exhaustion. In contrast, DFS requires only linear space $O(b \cdot m)$ where $m$ is maximum search depth. DFS is also effective in maze/satisfaction problems where many valid goal paths exist deep in the tree and finding any solution quickly is acceptable.
